Project Overview

Abstract

Face is a real-time human face emotion detection system built as a Final Year Project. It uses deep learning to detect and classify facial expressions in single portraits and multi-face group photographs.

Runs entirely in browser using TensorFlow.js and face-api.js — no server, no API keys, no data transmission. All processing is local and private.

Objectives

  • Detect and localize human faces using neural network face detection
  • Classify facial expressions into 7 base + 20 compound emotion categories with confidence scores
  • Support simultaneous multi-face analysis in group photographs
  • Estimate demographic attributes (age, gender) from facial features
  • Export results as JSON, annotated image, or HTML report
  • Maintain persistent history of all analysis sessions

AI Pipeline & Algorithm

4-stage sequential neural network pipeline:

01
Face Detection (TinyFaceDetector) — SSD architecture scans image at multiple scales to produce bounding boxes with confidence scores.
02
Landmark Mapping (68-point Net) — Regression network predicts 68 facial landmark coordinates for normalization.
03
Expression Recognition (FaceExpressionNet) — CNN outputs softmax probabilities across 7 base emotion classes.
04
Age & Gender (AgeGenderNet) — Multi-task network performs age regression and gender classification simultaneously.
// Core detection pipeline const opts = new faceapi.TinyFaceDetectorOptions({ inputSize: 608, scoreThreshold: 0.35 }); const dets = await faceapi .detectAllFaces(img, opts) .withFaceLandmarks(true) .withFaceExpressions() .withAgeAndGender();

20 Compound Emotions (Derived via Plutchik's Wheel)

Compound emotions are computed from weighted combinations of the 7 base emotions, following Robert Plutchik's psychoevolutionary theory of emotions. Each compound emotion represents a blend that captures nuanced human emotional states beyond basic categories.
